# REST API Perpustakaan Sederhana

Proyek REST API Perpustakaan menggunakan PHP Native (MVC Pattern), MySQL, dan Composer.

## Fitur Utama & Struktur Proyek
- **Authentication**: Token-based middleware (`Bearer secret-token-123`)
- **CRUD Books**: Endpoint `/api/books` (GET, POST, PUT, DELETE)
- **Error Handling**: Global Exception Handler & Standardized Response Format

## Ringkasan Pertemuan
- **Pertemuan 1**: Setup Environment & Structure
- **Pertemuan 2**: Database Connection & Basic CRUD
- **Pertemuan 3**: Advanced Routing & Middleware
- **Pertemuan 4**: Global Exception Handler, Response Helper, & E2E Testing
